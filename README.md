## Using the builder
 
**Option 1: Run locally**
 
1. Clone the repository:
```bash
git clone https://github.com/endritngjelina/App-Walkthrough-Builder.git
```
2. Open any `app walkthrough builder N.html` file in your browser (double-click it, or drag it into a browser window).
**Option 2: Download a single file**
 
Open the file on GitHub, click **Download raw file**, and open the saved `.html` file in your browser.
 
> Note: clicking an `.html` file on GitHub shows its source code rather than the rendered page. To use the builder, use one of the options above or enable GitHub Pages for this repository.

## Adding a new version
 
1. Create a new `.html` file following the existing naming pattern.
2. Keep it self-contained in one file so it works when opened directly.
3. Add it to the table in [Contents](#contents).
